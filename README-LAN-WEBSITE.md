# راهنمای اجرای سامانه SafeWatch HSE به عنوان وب‌سایت در شبکه داخلی (LAN)

این نسخه در برنچ `feature/lan-web-server` قرار گرفته و به شما اجازه می‌دهد رایانه واحد ایمنی و بهداشت (مثلاً با آی‌پی `10.1.1.63`) را به یک **سرور وب محلی (Intranet Web Server)** تبدیل کنید تا سایر کاربران و سیستم‌های کارخانه تنها با وارد کردن آدرس در مرورگر، وارد برنامه شده و اطلاعات را ثبت کنند.

---

### ۱. مراحل راه‌اندازی سرور در سیستم واحد ایمنی و بهداشت (`10.1.1.63`)

1. اطمینان حاصل کنید که **Node.js** روی سیستم نصب است (دانلود از [nodejs.org](https://nodejs.org)).
2. یکی از دو روش زیر را برای اجرای سرور انتخاب کنید:
   - **روش سریع:** روی فایل `Start-Web-Server.bat` یا `Start-SafeWatch-Server.bat` دوبار کلیک کنید.
   - **روش خط فرمان (ترمینال):**
     ```bash
     npm run server
     ```
     یا برای تعیین پورت اختصاصی (مثلاً ۳۰۰۰ یا ۸۰۸۰):
     ```bash
     node scripts/start-server.js 3000
     ```

3. پنجره سرور باز شده و پیام راه‌اندازی موفق و لیست آی‌پی‌های در دسترس مانند زیر نمایش داده می‌شود:
   ```
   =============================================================
      SafeWatch HSE Enterprise Intranet Web Server
   =============================================================
    [✓] پورت فعال سرور (Port):   3000
    [✓] دسترسی محلی:            http://localhost:3000
    [✓] آدرس برای سایر سیستم‌ها: http://10.1.1.63:3000
   =============================================================
   ```

---

### ۲. نحوه ورود سایر سیستم‌ها و کاربران در کارخانه

سایر همکاران در هر واحدی از کارخانه (نگهبانی، اداری، خطوط تولید، آموزش، مدیریت و ...) بدون نیاز به هیچ‌گونه نصب نرم‌افزار، تنها کافیست در مرورگر خود (Chrome / Edge / Firefox) آدرس زیر را باز کنند:

👉 **`http://10.1.1.63:3000`** *(یا آی‌پی سرور شما به همراه پورت)*

- نرم‌افزار به صورت وب‌سایت واکنش‌گرا و سریع لود می‌شود.
- تمام ثبت‌ها (تخلفات، تشویقات، چک‌لیست‌ها، بازرسی‌ها) مستقیماً و بلادرنگ در سرور مرکزی ذخیره و همگام‌سازی می‌شود.
