# SafeWatch HSE - Dedicated Frontend Client
## نسخه کلاینت مجزا (فرانت‌اند)

این دایرکتوری شامل نسخه کلاینت مجزای سامانه SafeWatch HSE است که می‌تواند به صورت کاملاً مستقل اجرا شده و به سرور مرکزی متصل گردد.

---

### ۱. ویژگی‌های کلاینت
- واسط کاربری مدرن با زبان فارسی و فونت وزیرمتن (RTL).
- ارتباط بلادرنگ (Real-Time SSE) با سرور مرکزی جهت دریافت آنی تغییرات دیتابیس PostgreSQL.
- قابلیت کش محلی (Offline-First) جهت ادامه فعالیت در صورت قطعی موقت شبکه یا در معادن و سایت‌های صنعتی.
- پنل‌های اختصاصی بر اساس نقش‌های سازمانی (مدیر کارخانه، منابع انسانی، افسر و مدیر HSE، انتظامات، آموزش و اداری).
- نمودارهای بصری پایش روند HSE با Recharts و گزارش‌گیری چاپی و اکسل.

---

### ۲. راه‌اندازی و اجرا
```bash
cd client
npm install
npm run dev
```

### ۳. اتصال به سرور مرکزی
به صورت پیش‌فرض کلاینت به سرور موجود در `http://localhost:3000` متصل می‌شود. برای تغییر آدرس سرور مرکزی:
در فایل `.env`:
```env
VITE_SERVER_URL=http://192.168.1.100:3000
```
یا از داخل منوی **«پیکربندی شبکه و دیتاسنتر»** در نوار بالای برنامه، آدرس سرور مرکزی را وارد نمایید.
